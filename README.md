# Мир сладостей — витрина

Фронтенд интернет-магазина «Мир сладостей» (Саратов): статические страницы,
без сборщика и фреймворков.

**Открытый сайт:** https://vdolesov.github.io/

Структура адресов повторяет текущий сайт mirsladostey164.ru, поэтому вёрстку
можно положить на существующий бэкенд без потери ссылок. Как это сделать —
в [INTEGRATION.md](INTEGRATION.md).

## Что внутри

| Файл | Назначение |
| --- | --- |
| `index.html` и папки разделов | 73 сгенерированные страницы |
| `products.js` | данные каталога: 44 позиции, 9 разделов |
| `app.js` | каталог, корзина, оформление, поиск, отложенные |
| `styles.css`, `theme-noir.css`, `pages.css` | оформление |
| `assets/products/` | фотографии каталога |
| `build/` | скрипты сборки и исходные материалы |

## Пересборка

Нужен Python 3 с Pillow и numpy:

```
python build/data.py        # products.js из build/catalog.json
python build/build_all.py   # все страницы
```

Локальный просмотр:

```
python -m http.server 4182
```
