# Mir Sladostey — storefront skin

Full static copy of mirsladostey164.ru with the new skin applied:
https://vdolesov.github.io/

- `skin/` — the skin itself, build scripts and install notes ([skin/README.md](skin/README.md))
- `assets/` — product photo series, hero and about images
- everything else — site pages at their original URLs, generated by `skin/build_site.py`
- `v1/`, `v2/` — earlier versions kept for reference: the July storefront (https://vdolesov.github.io/v1/) and the September rebuild on the live site's structure (https://vdolesov.github.io/v2/), exported from history by `skin/export_version.py <commit> <name>`. `v1/` additionally carries the store map and the footer of the current site (`v1/bottom.css`, `v1/bottom.js`, applied by `skin/v1_bottom.py`; re-run it after re-exporting); its Ossetian pie photos (801-803) are the current site's dark renders (`assets/products/80x-v9.webp` copied as `pies-80x-v8.webp`)
