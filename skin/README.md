# Скин для действующего сайта

Новое оформление для mirsladostey164.ru **без изменения вёрстки и логики**.
Сайт остаётся на 1С-Битрикс с шаблоном Aspro Максимум: те же компоненты, те
же адреса, тот же порядок работы. Меняется только внешний слой — цвет,
шрифты, фон, карточки.

Подключается одним файлом. Откатывается тоже одним — достаточно убрать
строку подключения.

**Готовая версия:** https://vdolesov.github.io/skin/demo/ — реальные страницы
сайта с подключённым оформлением: главная, разделы каталога, карточка товара,
корзина и контакты.

## Что меняется

| | Было | Стало |
| --- | --- | --- |
| Акцент | `#f3103a` — яркий красно-розовый | `#6d1226` — глубокий бордо |
| Наведение | `#f42d52` | `#8a1f36` |
| Фон страницы | чистый белый | тёплая бумага `#faf6ef` |
| Заголовки | Montserrat | Playfair Display (антиква) |
| Подвал и верхняя полоса | серые | тёплый тёмный `#1b1211` с золотыми подписями |
| Карточки товара | плоские | мягкая тень и подъём при наведении |
| Поля и кнопки | прямые углы | скругление 2 px, спокойные состояния |

Фирменный красный не исчезает — он уходит в глубокий бордо. Логотип и структура
страниц не трогаются, покупатель узнаёт сайт.

## Как подключить

1. Положите `skin.css` в шаблон, например
   `/bitrix/templates/aspro_max/css/skin.css`.
2. Подключите его **последним**, после стилей шаблона — в `header.php`
   шаблона или через настройки:

   ```php
   $APPLICATION->SetAdditionalCSS(SITE_TEMPLATE_PATH . '/css/skin.css');
   ```

   Либо просто добавьте в `<head>`:

   ```html
   <link rel="stylesheet" href="/bitrix/templates/aspro_max/css/skin.css">
   ```

3. Сбросьте кэш сайта: *Настройки → Автокеширование → Очистить файлы кэша*.

Порядок подключения важен: скин должен идти после основного CSS шаблона,
иначе часть правил не применится.

## Как собран

`skin.css` не написан вручную целиком. Скрипт `build_skin.py` берёт боевой
CSS шаблона, находит **все** правила с фирменным красным (260 штук) и
переписывает их новым цветом — так ни одно место не остаётся пропущенным.
Поверх добавляется небольшой ручной блок: шрифты, фон, карточки, формы.

```
python skin/build_skin.py    # пересобрать skin.css
python skin/build_demo.py    # обновить страницы демонстрации
```

Если в шаблоне что-то поменяется, достаточно перезапустить сборку.

## Фотографии

Отдельно подготовлена серия фотографий каталога в едином стиле: тёплый фон,
одинаковый габарит изделия, общая линия основания. Файлы лежат в
`../assets/products/` и названы по коду товара: `747-v7.webp` — это торт
«Прага», `747-v7-640.webp` — уменьшенная версия.

Чтобы использовать их на сайте, загрузите файлы в карточки товаров
инфоблока: имя файла совпадает с ID элемента. В демонстрации подмена сделана
скриптом — на живом сайте так делать не нужно.

## Что осталось за рамками

Скин не трогает разметку, поэтому не может изменить структуру блоков,
порядок элементов на странице или содержимое. Если понадобится поменять
сетку каталога, состав карточки товара или главную страницу — это уже
правка шаблона, отдельная работа.
